# Nonet — Sudoku practice studio

A Sudoku practice studio: play puzzles, generate fresh boards, and solve them,
with a calm interface built for practice. Named for the *nonet* — the 3×3 block
at the heart of every Sudoku grid.

**Live demo:** https://humaidi.me/nonet/

## Built with

React 19 · Vite · Tailwind CSS v4 · React Router · Zustand · Framer Motion

## Run locally

```bash
npm install
npm run dev
```

Open the printed local URL (the app is served under `/nonet/`). Build for
production with `npm run build`.
